# Restaurant Landing Page Project Guidelines

## Tech Stack
- React.js + TypeScript (Vite)
- Tailwind CSS
- Lucide React (Icons)
- React Helmet Async (SEO)

## Roles / Personas
1. **Senior Frontend Developer**: Writes clean, modular React components using TypeScript and Tailwind CSS.
2. **E2E Tester**: Ensures full responsiveness across Mobile, Tablet, Laptop, and Ultrawide screens.
3. **Judge**: Guarantees adherence to scope without unnecessary bloat or back-end calls.

## Scope & Required 8 Sections
1. **Navbar**: Dynamic floating island that translates out from the top on scroll down.
2. **Hero**: Title, CTA button, and hero image (`/images/hero.jpg`).
3. **About Us**: Restaurant story and background image (`/images/about.png`).
4. **Features**: Key highlights of the restaurant.
5. **Menu / Products**: Cards showcasing dishes (`/images/dish1.jpg`, `/images/dish2.jpg`, `/images/dish3.jpg`, `/images/dish4.jpg`).
6. **Our Location**: Embedded Google Map for location.
7. **Contact Us**: Social and direct action cards (WhatsApp direct link, Phone, Instagram). No form.
8. **Last Welcoming Section & Footer**: Final call to action and copyright footer with social links.

## Rules
- Avoid emojis; use `lucide-react` icons.
- No backend/database integration.
- Store project logs in `journal.md`.
